# Politique de confidentialité — Tappirgal Pulaar

La page publiée : **https://leonbathie.github.io/tappirgal-confidentialite/**

C'est l'adresse déclarée au Play Store pour le clavier **Tappirgal Pulaar**
(`com.pulaar.clavier`). Google exige une URL publique et stable ; ce dépôt
n'existe que pour la porter, et ne contient rien d'autre. Le code de
l'application reste dans son dépôt privé.

`index.html` en est la seule page, en français puis en anglais.

## La tenir à jour

Le texte fait foi sur ce que l'application envoie, et doit donc suivre le code.
La source vit dans le dépôt de l'application, en `docs/confidentialite.html` :
la modifier là, puis la recopier ici et pousser. Changer la date en tête des
deux versions, française et anglaise.

À reprendre, en particulier, si l'une de ces trois choses change : une
destination réseau nouvelle, une autorisation nouvelle au manifeste, ou une
donnée gardée plus longtemps qu'annoncé.
